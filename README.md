# cinemo-clone

HTML 과 CSS, GitHub의 사용법을 익히기 위해 구현한 가상의 OTT사이트 입니다.

## 주요 내용

- 주요 화면으로 이동할 수 있는 상단 네비게이션(메인 페이지 / 마이 페이지)
- 오늘의 추천 영화로 이루어진 메인 페이지
- 사용자의 프로필 확인과 찜목록을 수정 할 수 있는 마이 페이지
- 사용자의 계정을 변경할 수 있는 프로필 페이지

## 실행 방법 

- 다운로드 받은 cinemo-clone 폴더 내부의 index.html을 브라우저에서 실행한다.

- 혹은 하단 참고 자료의 링크를 통해 다운로드 없이 웹에서 실행한다.

### 페이지 내 이동 방법
- 페이지 상단의 **cinemo로고** / **홈**을 클릭하면 메인 페이지으로 이동한다.

- 페이지 상단의 **내가 찜한 콘텐츠** / **프로필 이미지** / **사용자의 마이 페이지**를 클릭하면 마이 페이지로 이동한다. 

- 마이 페이지의 **프로필 변경** 버튼을 클릭하면 프로필 페이지로 이동한다.

- 프로필 페이지의 **욜로**의 이미지나 이름을 클릭하면 메인 페이지로 이동한다.

## 폴더 구조

```cinemo-clone
├── assets/             # 이미지 및 SVG 그래픽 에셋 폴더
├── styles/             # CSS 스타일시트 폴더
│   ├── reset.css       # 브라우저 기본 스타일 초기화
│   └── style.css       # 메인 레이아웃 및 컴포넌트 스타일
├── index.html          # 메인 페이지
├── mypage.html         # 마이페이지
├── profile.html        # 프로필 선택 페이지
└── README.md           # 프로젝트 안내 문서
```
